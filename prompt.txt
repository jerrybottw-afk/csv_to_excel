請幫我用 Python 撰寫一個「CSV 批次轉 Excel 桌面小工具」，需求規格如下：

【技術與程式碼風格限制】

使用 Python 內建 tkinter 製作 GUI 視窗，搭配 pandas 與 openpyxl 處理資料。

必須採用程序化（函式式）寫法，嚴禁使用 class 類別封裝或過於複雜的進階語法，確保程式碼直覺、好閱讀與易維護。

【核心功能規格】

目錄掃描與勾選清單：可選擇 CSV 來源資料夾，自動掃描並列出所有 .csv 檔案（附捲軸），支援「全選 / 取消全選」與個別勾選（預設全選）。

編碼與資料格式保護：讀取 CSV 時自動相容常見編碼（utf-8-sig、utf-8、cp950、big5），所有欄位強制以字串（str）讀入並去除前後空白，避免店號、電話或郵遞區號遺失前導零。

雙輸出模式（預設合併模式）：

合併模式（預設）：將勾選的多個 CSV 匯出至同一個 merged_output.xlsx，一個 CSV 對應一個工作表（Sheet），並自動處理 Excel 分頁名稱 31 字元上限、非法字元替換與重複名稱防呆。

獨立模式：將勾選的每個 CSV 分別轉存為同名的 .xlsx 檔案。

自動建立輸出目錄：一律將結果輸出至「執行檔所在目錄底下的 output/ 資料夾」（若不存在則自動建立）。

Excel 排版優化：所有工作表皆凍結首列（A2），並依內容字元長度自動適配欄寬（中文字元寬度以 2 倍計算，並設定合理上下限）。

【UI 視覺設計】

介面配色需明亮、有層次（Colorful 風格），將色票與字型定義為集中於程式上方的常數，方便日後微調。
